# Documento de compatibilidad de privacidad y red

Este nombre de archivo se conserva para referencias históricas y scripts de versiones anteriores. Desde ZEUVE 0.9.0 la política vigente corresponde al **Descargador universal** y está documentada en `Docs/Modulos/Funcionales/UNIVERSAL_DOWNLOADER_PRIVACY_AND_NETWORK.md`.

La consulta de cookies del navegador está desactivada por defecto y solo se ejecuta tras activarla expresamente para la operación actual. No se persisten credenciales ni la selección del navegador. Tampoco se añaden telemetría, APIs externas ni actualizaciones automáticas. La red se utiliza solo tras una acción expresa de análisis o descarga; el historial y los registros continúan aplicando minimización y saneamiento de URLs.
