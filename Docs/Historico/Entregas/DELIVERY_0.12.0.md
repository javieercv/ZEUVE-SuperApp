# Entrega — ZEUVE 0.12.0

## Estado

La carpeta activa `ZEUVE_Swift` contiene el código fuente de ZEUVE 0.12.0, build interno 42, y Descargador universal 0.7.0. Se mantiene una única copia activa y no se entrega ningún ZIP.

## Contenido

- Perfiles editables para todas las plataformas incorporadas.
- Restauración individual y global de los valores de fábrica.
- Reglas personalizadas por dominio con control opcional de subdominios.
- Persistencia local minimizada y migración de los ajustes existentes.
- Resolución por elemento y prioridad explícita de los controles manuales.
- Modo manual «Original».
- Interfaz, manifiesto, proyecto Xcode, documentación y pruebas actualizados.
- Verificación integral completada sin fallos y aplicación Debug ARM64 generada correctamente por Xcode.

## Privacidad

Una regla personalizada persiste únicamente el dominio normalizado. No guarda la ruta del enlace, parámetros, fragmentos, credenciales, cookies, proxy, carpeta de salida ni URLs multimedia firmadas. Crear una regla no amplía la compatibilidad de los motores ni provoca conexiones por sí mismo.
